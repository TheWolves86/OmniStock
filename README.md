# OmniStock

A mobile inventory and billing management app built with React Native,Expo and SQLite.

## About

OmniStock helps small business owners manage products, inventory, stock levels, and customer billing from a single mobile application.

The app was designed for local stores such as:

* Kirana(grocery) Stores
* Saree(A indian cloth) Shops
* Clothing Stores
* General Retail Businesses
* Small Buisnnes owners
* Your ai ecommerce platform

Users can add products, generate bills, track inventory, monitor low-stock items, and view billing history and manage ur buissnees overall.

## Features

### First-Time Setup

* Three-screen onboarding experience
* Store setup screen
* Store name configuration
* Business template selection *(currently only for selection, does not affect the app yet)*
* Employee setup option *(reserved for future updates)*

### Inventory Management

* Add new products
* Edit existing products
* Delete products
* Organize products by category
* Search products instantly
* Filter products by category
* Set low stock thresholds

### Billing System

* Generate invoices
* Add multiple products to a bill
* Update product quantities
* Automatic GST calculation
* Multiple payment methods

  * Cash
  * Card
  * UPI
* Customer information

  * Name
  * Phone Number
  * Address
* Automatic stock reduction after every successful sale

### Billing History

* View all previous invoices
* Customer information
* Purchased products
* Payment method
* Invoice totals
* Detailed invoice popup

### Dashboard

* Total products overview
* Inventory value
* Total bills generated
* Low stock alerts
* Quick action shortcuts
* Personalized store greeting

### Settings

* View store information
* Reset onboarding
* Reset store setup
* Delete all application data

### Frontend

* React Native
* Expo
* Expo Router
* TypeScript

### Local Storage

* SQLite (expo-sqlite)
* AsyncStorage
