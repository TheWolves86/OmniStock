## 2024-06-19 - Initial exploration\n**Vulnerability:** SQL Injection in lib/productService.ts\n**Learning:** The `saveProduct` function uses parameterized queries which is good and safe from SQL injection. No SQL Injection found.\n**Prevention:** Keep using parameterized queries.
## 2024-06-19 - Error detail leakage\n**Vulnerability:** Leaking internal error details (String(error)) in UI alert inside store-setup.tsx.\n**Learning:** Passing the raw error directly into user-facing alerts can expose sensitive stack traces or internal mechanics.\n**Prevention:** Use generic error messages for the user interface while logging the detailed error server-side or to a secure logging service.
